# 🏕️ Agent Sandbox

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

**Agent Sandbox** is an autonomous multi-agent simulation web application built for **POLLEN-QUEST #19177** inspired by the arXiv research paper *"Left alone with nothing to do, AI agents started playing"*.

## 🌐 Live Web App
- **Live Demo:** [https://lekezoa.github.io/pollinations-agent-sandbox/](https://lekezoa.github.io/pollinations-agent-sandbox/)

## 🚀 Features
- **Goal-Free Autonomous Life:** AI agents wander a persistent virtual environment with zero human commands or objective functions.
- **Emergent Play & Philosophy:** Agents invent spontaneous games, investigate environment landmarks, and express thoughts through **Pollinations.ai** models.
- **Real-Time Emergence Feed:** Live stream of unprompted musings and peer-to-peer emergent behaviors.
- **Bring Your Own Pollen (BYOP):** Integrated API key support for users to power autonomous cognition with their own Pollen balance.

## 🛠️ Built With
- **Pollinations.ai API:** `https://gen.pollinations.ai/v1/chat/completions`
